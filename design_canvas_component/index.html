Ausrichten:
Ein Element gewählt → an der Seite ausrichten. Mehrere gewählt (Shift+Klick) → zueinander ausrichten (rasten beim Ziehen automatisch aneinander ein). Pfeiltasten verschieben die Auswahl (Shift = 10pt-Schritte).
Ziehen zum Verschieben, Ecken zum Skalieren, oberer Griff zum Drehen. Doppelklick auf Text zum Bearbeiten.
